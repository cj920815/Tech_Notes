# 科技知识导航网站

一个具有科技风格的链接导航网站，支持管理员编辑和用户浏览功能。

## 功能特点

- **管理员功能**：
  - 链接添加/删除/编辑
  - 分类管理
  - 控制链接显示/隐藏

- **用户功能**：
  - 按分类浏览链接
  - 查看链接点击数
  - 确认对话框交互

- **设计风格**：
  - 科技风格界面
  - 动态粒子效果
  - 响应式设计，适配移动设备

## 使用说明

### 管理员登录

1. 点击页面右上角的"管理员登录"按钮
2. 输入管理员用户名和密码

### 管理链接

登录后，您可以：

1. **添加链接**：点击"添加新链接"按钮，填写链接信息
2. **编辑链接**：点击链接旁边的编辑图标
3. **切换显示/隐藏**：点击眼睛图标可以控制链接是否在前台显示
4. **删除链接**：点击垃圾桶图标可以删除链接

### 用户浏览

1. 用户可以通过顶部的分类按钮筛选不同类别的链接
2. 点击链接时会弹出确认对话框，点击"好"后才会跳转到目标网站
3. 每次点击都会增加链接的浏览量计数

## 技术实现
- LeanCloud 后端存储链接和其他数据
- 使用环境变量管理敏感信息

## 本地开发

1. 克隆仓库到本地
2. 在项目根目录创建 `.env` 文件，配置以下环境变量：

```
# LeanCloud配置
LEANCLOUD_APP_ID=你的应用ID
LEANCLOUD_APP_KEY=你的应用Key
LEANCLOUD_SERVER_URL=你的服务器URL

# 管理员账号信息
ADMIN_USERNAME=你的管理员用户名
ADMIN_PASSWORD=你的管理员密码

# 联系信息
HELP_CONTACT=联系方式
```

3. 使用本地服务器运行项目：`npx serve .`

## 部署到Vercel

1. Fork或克隆此仓库到您的GitHub账户
2. 在Vercel上创建新项目，关联此仓库
3. 在Vercel项目设置中添加以下环境变量（不需要添加@前缀）：
   - `LEANCLOUD_APP_ID` - 您的LeanCloud应用ID
   - `LEANCLOUD_APP_KEY` - 您的LeanCloud应用Key
   - `LEANCLOUD_SERVER_URL` - 您的LeanCloud服务器URL
   - `ADMIN_USERNAME` - 管理员用户名
   - `ADMIN_PASSWORD` - 管理员密码
   - `HELP_CONTACT` - UP主联系方式
4. 部署项目

如果您在部署过程中遇到问题，请尝试以下解决方案：

- 确保所有环境变量都已正确设置
- 在Vercel项目设置中，将"Build Command"设置为`npm run vercel-build`
- 如果遇到构建错误，可以在Vercel的部署日志中查看详细信息

## 注意事项

- 所有敏感信息已使用环境变量管理，不再使用硬编码
- Vercel部署时会自动运行`env-plugin.js`脚本生成配置
